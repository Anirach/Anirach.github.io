**Five operating principles (printed p. 21 EN / p. 22 TH), verbatim — quote exactly ONE in the 💡 blockquote and list the rest in prose; never renumber:**
1. **Decompose work at the decision level** Redesign tasks that create the outcome rather than automating a job title. — แยกงานในระดับการตัดสินใจ ออกแบบ Task ที่สร้างผลลัพธ์ ไม่ทำตำแหน่งงานทั้งตำแหน่งให้เป็นอัตโนมัติ
2. **Place people where judgment changes the result** Reserve expertise for purpose exceptions commitments and ambiguity. — วางคนในจุดที่วิจารณญาณเปลี่ยนผล ใช้ผู้เชี่ยวชาญกับเป้าหมาย ข้อยกเว้น คำมั่น และความกำกวม
3. **Do not use attention to enforce what software can enforce** Permissions schemas and limits belong in hard controls. — อย่าใช้สมาธิมนุษย์บังคับสิ่งที่ซอฟต์แวร์บังคับได้ สิทธิ์ Schema และวงเงินควรเป็น Hard Control
4. **Design review as operating capacity** Specify competence evidence time queue limit and authority to reject. — ออกแบบการตรวจเป็นกำลังการผลิต ระบุคุณสมบัติผู้ตรวจ หลักฐาน เวลา ขนาดคิว และอำนาจปฏิเสธ
5. **Preserve skill formation** Decide how novices build judgment if AI performs the routine cases that once trained them. — รักษาเส้นทางสร้างทักษะ หาก AI รับงานพื้นฐาน ต้องตอบให้ได้ว่าคนใหม่จะสะสมวิจารณญาณจากไหน

In human-plus-AI work, the model gathers, predicts, summarizes, or proposes while a person judges. In AI-first work with human oversight, the system handles normal cases within bounds and people supervise or resolve exceptions. […] Reskilling therefore means more than prompt instruction. It means preparing people for the changed task mix and preventing scarce experts from becoming a review bottleneck.

### N1 — 14% average, 34% for novices, minimal for the most experienced
- **Value / unit:** +14 % (average), +34 % (novice and low-skilled), ≈ no change (experienced and highly skilled) — issues resolved per hour.
- **Denominator / population:** 5,179 customer-support agents at one firm.
- **Comparison:** agents with access to the generative-AI conversational assistant vs agents without, using the staggered rollout.
- **Task / setting:** customer support, conversational assistant, one firm, one workflow, one period.
- **Source:** [5] Brynjolfsson, Li & Raymond, "Generative AI at Work", NBER WP 31161, April 2023. Abstract verbatim: *"we study the staggered introduction of a generative AI-based conversational assistant using data from 5,179 customer support agents.
